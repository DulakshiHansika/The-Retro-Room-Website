# The-Retro-Room-Website - Responsive Vintage Boutique Web Page

A stylish, fully responsive single-page website designed for a vintage boutique shop called **"The Retro Room"**. This project showcases the combined use of semantic HTML5, custom CSS3 styling, and clean JavaScript functionality to deliver a seamless user experience across modern devices.


# Features & Implemented Requirements

This project successfully fulfills all core web design requirements:
  * Responsive Layout: Designed from scratch using CSS Flexbox, Grid, and Media Queries to ensure flawless viewing on desktops, tablets, and  smartphones.
 * Curated Visual Gallery: Features 5 high-quality aesthetic layout images showcasing different vintage categories.
 * Interactive JavaScript Element: Includes a "Claim Daily Offer" button that dynamically triggers a native JavaScript function (`revealWelcome()`) to display a 20% discount code without refreshing the page.
 * Styled Data Table: A clean, organized HTML table displaying the boutique's structural opening and closing hours.
 * Semantic Structure & Content:** Uses an unordered list (`<ul>`) to present key brand values, paired with custom typographic formatting.
 * Navigation Links: Features 5 functional hyperlinks (4 scroll-anchors in the sticky top menu and 1 "Back to Top" footer link).
 * Smooth CSS Animation:** The landing header text utilizes an elegant `@keyframes slideIn` slide-down and fade-in entry effect on page load.

Technologies Used
 * HTML5 - Page structure and semantic formatting.
 * CSS3 - Custom variables, typography, grids, flexbox, and responsive design animations.
 * JavaScript (ES6) - Client-side interactive DOM manipulation.
